# Post-Cold War PRC Policy Primary Sources

This folder contains a FRUS-style static research assist page for historians working on U.S. policy toward the People's Republic of China after the Cold War.

The page is built as a one-stop source desk for the 1989-2001 arc from Tiananmen and Bush administration sanctions/repair through Clinton administration MFN, WTO, summitry, Taiwan, human-rights, and PNTR policy.

Open locally:

```bash
open index.html
```

GitHub Pages bundle:

```bash
npm run build:site
```

The build script copies this directory into `site/PRC-PostColdWar/`.
